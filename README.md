# Myshirt — West Coast t-shirt store

Original West Coast tees from Sooke, BC. Express + JSON file store + Stripe Checkout (test mode), with an owner admin panel.

```bash
npm install
cp .env.example .env.local   # optional: ADMIN_PASSWORD, Stripe test keys
npm start                    # http://localhost:4317  ·  admin: /admin (default password: sooke-tides)
```

- Storefront `/` · content pages `/page/about|faq|policy` · order confirmation `/success` · owner admin `/admin`
- 42 original SVG designs generated by `npm run gen:designs` → `public/designs/`
- Without a `sk_test_` key, checkout runs a **demo flow** (order recorded, no card charged).
- Full docs for collaborating bots: `/workspace/shared-web-projects/myshirt/README.md` (on the shared box).
